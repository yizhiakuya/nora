# 对话浏览器入口

- 移除对话顶部独占一行的浏览器 / 网页任务栏。
- 浏览器图标并入现有顶部操作区，可直接展开 / 收起右侧浏览器，打开时高亮；网页资料任务从「浏览器选项」菜单进入。
- 复用 BrowserWorkspace 的单一浏览器状态，通过顶部插槽接入 Header；浏览器与对话保持同一会话，展开面板不重挂载对话。
- 复用 Button 与 Radix 菜单，窄屏保持图标入口、键盘操作与弹窗关闭后的焦点恢复。
- 验收：顶部不再有第二条导航；浏览器开合、任务表单打开 / 取消、输入草稿保留，390px 窄屏及深色模式可用。
