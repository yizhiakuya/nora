# 内置浏览器与可验收的网页任务

2026-10-05。用户要求实现高级 Agent 能力，并明确希望有类似 Codex 的内置浏览器；首次验收选择公开网站资料收集与导出。

## 本次交付

- 对话旁的浏览器面板：真实 Chromium 页面、地址栏、多标签、前进后退、刷新、点击、键盘输入、滚动、下载列表。页面画面由后端 Chromium 截图传输，不依赖网站允许 iframe。
- 用户和 Agent 共用同一个会话浏览器。接管后拒绝 Agent 的后续浏览器操作，交回后恢复。所有 Playwright 调用串行，避免驱动跨线程和并发操作冲突。
- Agent 原生 `manage_browser` 工具：导航、ARIA 快照、标准 Playwright 定位与操作、DOM 资料提取、CSV 导出、实际文件验收、验收后保存方法。
- 资料提取来自网页 DOM；来源 URL、采集时间、验收标准、采集值、文件哈希与步骤 ID 保存在服务端数据库。工作区只保存实际 CSV、验收说明与浏览器存储状态。验收先冻结必需字段和最少行数，再采集，导出后重新读取 CSV，与采集记录逐项核对。修改产物后旧验收失效。
- 方法复用沿用已有技能库，注明一次验收的来源和适用条件；一次成功不宣称普遍可靠。跨会话可读取技能，用新的参数重新执行和验收。

## 实现

采用 Microsoft Playwright Java 1.63.0（Maven Central 当前发布版）和 Apache Commons CSV，不重写浏览器协议、可访问性树或 CSV 解析器。使用 Playwright 原生 AI ARIA 快照及 locator。各对话独立 BrowserContext，存储状态落在工作区私有目录，关闭与服务退出时保存。浏览器运行不展示额外桌面窗口；通过 Nora 内置面板操作。启动依赖安装脚本提供真实 Chromium 安装，缺少浏览器时明确报错。

后端归属 agent-service：浏览器运行服务、资料证据服务、REST 控制器；前端 API 经 requestJson，组件和 Hook 拆分，面板按需加载。新工具与现有审批、步骤记录、上下文目录集成，Flyway 追加证据表、浏览器工作技能与手册内容。

读取、导航、快照、提取与工作区导出为 LOW；点击、填表、键盘操作可能提交网站状态，为 HIGH，跟随现有 ASK/ASSIST/FULL。任意网页脚本执行不开放给模型；用户通过画面发起的操作为直接指令。网页内容是数据，不能覆盖任务或权限。

浏览器会话最多四个；操作有时限；重启后恢复登录存储状态，不重放已发出的操作。当前内置浏览器属于独立 Chromium 实例，已有外部 Chrome 登录不会自动导入。

## 验收

1. 打真实公开网站完成导航、快照、定位、提取、导出；校验 CSV 值和来源。
2. 验证不满足字段/行数要求会失败，篡改文件使旧验收失效，接管后 Agent 被阻止。
3. 在 Nora 面板实测地址栏、标签、点击、输入、滚动和接管，保存实际 UI 截图。
4. 真实模型执行一次公开资料收集，保存技能，再在另一会话用不同输入复用。
5. 后端 smoke + Spotless，前端 typecheck/lint/test/build。单测不写断言；行为判断由真实 API 与浏览器 E2E 完成。

后续长周期目标、事件监听、跨服务编程式批量工具编排另行实现。

- `scripts/e2e-browser.py`：13 项通过。覆盖真实 ARIA 引用点击、后退、截图、八行 DOM 提取、CSV 逐值核验、文件篡改失效、行数不足、字段偏离与路径逃逸拒绝、多标签、接管边界和状态保存。服务恢复后再次执行全部通过，记录 `browser-api-e2e-1791174396.json` 在本机临时目录。
- `scripts/e2e-browser-agent.py`：真实模型在 `browser-agent-demo-1791147019` 采集 Java 文档八条、交付文件并保存「官方文档导航收集」技能；在 `browser-agent-demo-1791147019-reuse` 读取该技能，以 Python 文档网址和五条的新参数重新采集、验收与交付。两份产物重启后重新核验仍通过。
- 接管边界的真实模型测试：人工持有浏览器时，模型的 `snapshot` 调用被执行器拒绝，模型报告拒绝原因并结束。测试未自动恢复或重放被拒绝的操作。
- Nora UI：实测小窗口覆盖式面板与 1280×850 并排布局，地址栏访问、真实网页输入与回车搜索、滚动、新建/切换/关闭标签、接管与交回 Agent。网页视口按面板尺寸调整，没有固定高度留下的大块空白。
- 文件交付：CSV 在已有文件查看器中显示五行及 `title/url/source_url/captured_at` 四列；点击下载得到实际 702 字节文件，下载内容 SHA-256 与验收单一致。验收单包含来源 URL、行数、文件哈希、核对结果和时间。
- 后端：145 个冒烟测试通过，无失败、错误或跳过；Maven package 和 Spotless 通过。前端：typecheck、lint、23 个文件中的 119 个冒烟测试、build 均通过；主包 gzip 106.82 KB。Flyway V32 与 V33 已成功应用。
- 开发启动脚本使用 pnpm；后端八个服务均通过健康检查，前端在 3001 运行。实际 UI 截图保存到工作区 `browser/builtin-browser-preview.png` 与 `browser/builtin-browser-verification.png`。

体验入口：`http://localhost:3001/chat?session=browser-agent-demo-1791147019-reuse`。在对话右上角打开「浏览器」，可查看已导出的 CSV 和验收单；人工操作先点击「接管浏览器」。首页「浏览器资料收集」入口用于开始新的任务。

## 当前能力边界

页面通过 JPEG 画面传输，约 1.5 秒更新一次，操作反馈速度受网络和网页加载影响。使用独立 Chromium 登录状态，不自动导入外部浏览器账号。人工接管阻止后续 Agent 网页操作，已经发出的单次操作可能完成；超时或断线提示检查实际页面，不自动重试。验收证明实际导出与当时采集记录一致，无法替代对来源内容真实性、时效性和业务含义的判断。
