# 按钮与输入交互统一

需求：合并发送/停止，统一全站按钮和常用交互细节。

范围：Button、Select、DropdownMenu、Input、Checkbox、Switch 公共原语；首页与会话输入区。复用 useChat 的发送、停止、排队状态与原处理函数，不增加一套请求状态。图谱工具不可用，按源码与引用检查调用链。

设计：主操作/次操作/工具栏保持层级，统一边框、焦点、短过渡、展开态与禁用反馈，去掉全局按下位移。图标默认尺寸放在低优先级样式层，允许已有小图标尺寸真正生效。首页和对话的发送使用同一圆形中性主按钮样式。

会话右下角只有一个主按钮：空闲为发送箭头；运行中为停止方块，草稿和附件上传不禁用停止；停止中显示 loading 并禁用重复停止。有草稿/附件的运行中会话显示独立的轻量排队栏，调用原 onSend；Enter 仍发送/排队，Shift+Enter 换行，中文组合输入和引用菜单优先级保持。运行中排队与本地斜杠命令仍走 useChatCommands。

验证：状态冒烟、前端质量门、真实会话发送/停止/追加、键盘与菜单、首页、设置、浅深色和窄屏、build preview，结束恢复 dev。不改后端协议。
