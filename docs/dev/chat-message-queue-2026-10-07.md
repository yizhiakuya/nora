# 对话消息排队

- Agent 运行中按发送或 Enter，新消息显示在输入框上方，默认在当前任务正常结束后依次发起新轮次。
- 点击「插入」调用现有 steer 接口，在下一次模型请求前加入当前轮的用户消息，不中断正在执行的工具。
- 尚未发送的消息可删除；「撤回编辑」恢复正文、附件引用和检索范围，保留输入框已有草稿。
- 队列复用现有会话 store，刷新和切换会话保留；停止或报错后保留队列，用户可手动发送。
- 插入请求沿用稳定消息 ID。网络响应不确定时保留待确认项，重试确认后才移除，避免重复插入或假撤回。
- 一次运行可包含多条聊天消息。插入受理时在现有步骤流中记录边界，实时展示按边界分段；运行结束按同一边界保存独立消息，保持「已有 AI 内容 → 用户插入 → 后续 AI 内容」的顺序。工具更新按原步骤 ID 留在原位置。

验收通过：真实模型验证默认排队、连续插入与后续普通排队、删除、撤回、停止后保留及手动恢复；运行中与结束后刷新顺序一致，工具步骤没有跨消息重复。浏览器验证 390px 窄屏和深色模式；原主题和临时视口已恢复。

前端类型检查、Lint、125 项冒烟测试及生产构建通过；后端相关 40 项冒烟测试通过，已打包并重启。`scripts/e2e-chat-state.py` 对真实插入的消息顺序、后续消息和步骤唯一性留下可重跑检查。
