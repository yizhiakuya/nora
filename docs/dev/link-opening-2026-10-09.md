# 工作区内容链接打开方式

## 需求与职责

- 文档预览、对话和采集结果中的 HTTP/HTTPS 链接，普通点击默认在现有侧面工作区的内置浏览器中新建标签页，保留原文件和网页标签。
- 「设置 → 通用 → 链接打开方式」提供内置浏览器和外部浏览器。复用 `usePreferences` 持久化，即时生效，旧用户没有该字段时采用内置浏览器默认值。
- 内容链接共用 `BrowserLink`，Markdown 原有文件解析和点击处理先执行。网页打开由已有 `useBrowser` 控制，复用 `act` 队列、原始错误显示与 `useFileViewer.openBrowser` 的未保存修改保护。
- 用户点击内容链接属于人工浏览操作：需要时先走现有 `takeover`，再执行 `open` + `newTab: true`；失败显示现有浏览器错误，停止后续动作。原 Agent 网页不会被覆盖，可通过已有「交给 Agent」恢复控制。
- 外部模式在访问 Nora 的浏览器中新开标签，使用 `noopener noreferrer`。保留 Ctrl/Cmd/Shift、鼠标中键的浏览器原生行为。
- 文件引用、相对文件路径、页面锚点和下载保留原处理。登录授权及明确标为「外部打开」的入口继续使用现有原生链接。HTML 沙箱预览不调整。

## 最小改动与验收

调整 `usePreferences`、`GeneralSettings`、`useBrowser`，增加一个共享内容链接组件；Markdown 和采集结果表使用该组件，不增加浏览器实例或第二套标签状态，不改后端契约。

真实点击验证发现原 `useBrowser` 将组件存活标记放在轮询 effect 中；面板切换触发轮询清理时会误判组件已卸载，跳过排队命令且未扣减 pending。组件存活由独立的挂载 effect 管理，轮询清理只取消轮询；队列的提前退出也经过 finally，确保忙碌计数归还。

验收：真实文档点击后新建内置网页标签、保留原标签、再次点击再新建；切换外部模式后在客户端新开标签、刷新设置保留；文件和下载路径不受影响；窄屏与深色模式；类型检查、Lint、冒烟测试及生产构建。
