- 输入栏提供「推理摘要：简洁 / 详细」快捷选择，默认简洁，复用本地偏好持久化。
- 简洁默认折叠工具参数、结果和思考正文；详细自动展开这些详情。单行状态与 token 计数保持可见，手动展开或收起优先。
- 工作过程在执行中展开；结束时，未手动查看过的过程自动收起。详细模式自动展开本身不算手动查看。

- 收起过程仍展示成果卡片，回答、错误、待批准与提问入口不受影响。
- 实测偏好刷新恢复、两种模式、未查看自动收起、手动查看后保留、窄屏与深色显示。
