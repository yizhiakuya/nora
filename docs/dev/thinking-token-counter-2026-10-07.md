# 思考 token 计数

- 在真实思考步骤的摘要行显示 `≈1.2K tokens`，只统计本段已收到的思考文本；不足 1,000 保留整数，达到 1,000 后用 K，最多一位小数（1,100 → 1.1K，整数省略 .0）。
- 执行中每秒采样一次，结束立即显示完整文本的估算值；折叠不影响采样，卸载或停止后清理计时器。
- 复用现有 CJK/ASCII 字符权重，不把 SSE 分片数当 token 数，也不把整轮输入、回答和工具用量计入思考。
- `≈` 与悬浮说明明确估算口径，精确整轮用量仍来自上游 usage；历史文本可直接恢复计数。
- 浏览器真实模型验收计数增长、结束保留、刷新恢复和窄屏显示。

## 验证

- 类型检查、Lint、118 项冒烟测试和生产构建通过。
- 实际模型思考流中观察到估算值从 12,187 增至 24,610；结束的思考段保留 25,995 tokens，历史会话重新加载也显示计数。
- 390 × 844 视口没有横向溢出；浅色与深色显示正常，验收后恢复原主题与视口。
