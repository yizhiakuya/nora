# Nora 界面统一

统一中性底色、主题变量与基础组件，减少各业务页自行定义颜色、间距和控件尺寸。

覆盖首页、侧栏、聊天过程和输入框、资料、任务、数据源、环境，以及设置中的模型、连接和技能管理。

实现复用现有 Tailwind 与 Radix；样式约定见 `nora-web/AGENTS.md`。业务数据继续读取真实后端。

## 验证

- `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build`。
- 24 个测试文件、117 项冒烟测试通过；主入口 gzip 约 120KB。
- 320px、390px、768px 与桌面宽度；浅色及深色。
- 分类键盘切换、自定义技能筛选、真实文件预览、弹窗焦点恢复、聊天工具详情、手机导航。
- 快速查找复用 Radix 弹窗，自动聚焦输入；Tab/Enter 打开搜索结果，Escape 返回触发按钮；390px 无横向溢出。
- MCP 工具说明和技能详情仅查看，不修改配置或触发任务。

页面截图保存于 `agent-workspace/browser/ui-style-*.png`。
