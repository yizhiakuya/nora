# Nora 流畅交互打磨

## 定位与依据

延续个人 AI 工作台与暖灰桌面工具风格，让用户从输入目标、查找资料到查看结果保持连续的工作节奏。「丝滑」定义为及时反馈、稳定布局、可预测的动效和完整的键盘路径。

- [Carbon Motion](https://www.carbondesignsystem.com/building-blocks/foundations/motion/overview)：高频操作采用克制的 productive motion；按交互尺度安排时长。
- [web.dev 动画性能](https://web.dev/articles/animations-guide)：位移与透明度优先，不为每个元素增加合成层，不用动画宽高驱动整页重排。
- [web.dev INP](https://web.dev/articles/inp)：200ms 是良好响应的指标上限，并非动画时长或本次已测成绩。
- [W3C 动效可访问性](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions)：尊重系统减少动态效果，保留信息与操作反馈。

## 现状与最小方案

链路：App/Page → RouteShell → Sidebar + SideWorkspace → 页面 Header/内容；首页复用真实会话、资料选择、运行任务和成果接口。各领域弹窗共享 Radix Modal，菜单复用现有 UI 原语。

1. 首页收敛到同一 820px 内容轴，强化输入与快捷任务的层级，快捷入口直接显示用途。保留发送、引用、项目选择与真实结果的数据归属。
2. 共享 CSS 定义 120/180/220ms 节奏与统一缓动。按钮提供轻微按压反馈，内容短暂淡入，弹层进入/退出对称；滚动区预留滚动条，减少横向跳动。减少动态效果时取消位移和循环动画。
3. 路由懒加载保留工具栏高度与内容骨架，提供可读状态。首页异步区域预留空间，错误原文与重试继续可见。
4. 手机导航使用已有 Radix Dialog 的焦点约束、Escape、遮罩和关闭后焦点恢复；桌面侧栏保持原偏好。切换到桌面时关闭手机弹层，避免隐藏遮罩锁住页面。侧栏宽度切换不再逐帧挤压主内容。
5. 实测资料搜索无结果时没有说明、仍显示无关文件夹入口。统一列表/网格的搜索展示：搜索时只展示匹配文件、显示匹配数；成功读取但无匹配时提供空态和清除搜索，失败时继续展示原错误。
6. 弹窗和侧面工作区在隐藏原页面、子元素自动聚焦与懒加载之前记录入口；关闭后恢复入口焦点且不滚动页面。工作区继续由原状态仓库管理，入口记录归布局组件，不进入业务状态。

范围：首页、快捷入口、Sidebar、App 加载态、公共样式/按钮/弹层/标签、相关冒烟与规范。无新依赖、后端接口或数据迁移。图谱工具未提供，使用源码和引用检索补足。

## 验收计划

执行 typecheck、lint、deadcode、test、build；真实后端下检查首页、资料、任务、设置、历史会话，桌面/390px/明暗主题，弹窗与手机导航的 Tab/Escape/焦点恢复，空态/错误态与减少动态效果。记录实际结果，不将局部验收称为全业务回归或性能达标。

## 实际结果

- 最后修复工作区焦点后，typecheck、lint、deadcode、test、build 全部通过。全量冒烟 43 文件 / 157 项通过，包含自动聚焦弹窗与 StrictMode 下工作区首次加载、重复打开、返回和 Escape 路径。主包 gzip 125.18KB。保留既有 `useChatSessions` 静态/动态混合导入构建提示。
- 本地真实后端，先开发模式，再用 3001 生产预览检查，确认加载 `/assets/` 构建资源。
- 1280px 浅色/深色首页；390px 首页、资料、任务、历史会话没有页面横向溢出。既有真实会话正文、运行记录、成果仍可见。
- 手机导航打开后焦点在弹层内；Shift+Tab 保持在弹层；Escape 关闭后焦点返回导航按钮；选择资料页后关闭；手机弹层展开时切回桌面自动关闭。
- 文件夹/任务弹窗正常展示，任务弹窗 Escape 关闭后回到创建按钮；会话操作菜单与主题下拉正常打开关闭。未创建任务或文件夹。
- 资料搜索 `uiux-no-result-20261017` 显示「找到 0 个文件」和「未找到匹配的文件」；清除搜索后恢复 11 个根目录文件与 1 个文件夹。浏览器脚本对空态可见性做结果检查。
- 生产预览下停止本轮启动的本地后端：首页先显示 HTTP 错误与「上次成功读取」标识，后出现服务不可用覆盖层；重新启动并确认健康后覆盖层消失，「UIUX 验收草稿，不发送」完整保留，随后清空验收草稿。未发送模型请求。
- 首页资料选择弹窗可读取真实文件，主题已恢复验收前的浅色。
- 带 `autoFocus` 输入框的弹窗修复已补完真实后端浏览器验收：文件、知识库、新建文件夹、全局搜索通过 Escape、关闭或取消退出后回到触发按钮；接入服务商、新建连接、添加纳管服务也恢复入口焦点。之前浏览器访问受限的未验项已解除。
- 数据源弹窗内选择器先按 Escape 只关闭下拉并恢复选择器焦点，再按 Escape 关闭弹窗并恢复「新建连接」。退出动画完成后检查 DOM 焦点。模型、环境页签支持方向键切换；主题选择器关闭恢复自身焦点。
- 390px 下补验设置、会话、Agent、数据源、环境，无页面横向溢出；新建连接弹窗宽 366px，左右各留 12px。手机导航内打开全局搜索，关闭搜索后回到导航搜索按钮，选择页面后导航关闭。会话搜索无匹配时显示明确空态，清空后恢复列表。
- 本轮发现手机首次懒加载工作区时记录入口过晚，返回后焦点落到 body。将入口记录提前至 SideWorkspace，WorkspacePanel 负责聚焦与卸载恢复；刷新页面后的首次返回、重复打开后 Escape 均通过浏览器结果断言。桌面分隔条方向键调整宽度、展开后 Escape 恢复并排、关闭最后标签恢复入口均通过；宽度恢复为验收前 70%，临时空白标签已关闭。
- 本轮追加验收使用开发服务与真实后端，未再次切换生产预览；新的生产构建已通过。
- 减少动态效果的样式已覆盖时长、循环、延迟和按压位移；当前浏览器控制接口未提供媒体偏好模拟，因此未实测操作系统切换，未测真实 INP/帧率。
