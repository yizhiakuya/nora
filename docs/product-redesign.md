## 6.5 信息架构原则（2026-09-03 收敛）

- **侧栏只放高频工作区**（9 项）：首页/文件/对话/知识库/AI 能力/数据源/环境控制台/自动任务/设置
- **模型管理**是低频配置 → 设置子页（`设置 → 模型管理`），对话页模型显示直达
- **环境变量** = 用户自定义凭据 KV（GH_TOKEN 等，`{{KEY}}` 引用）→ 设置子页（`设置 → 环境变量`）；secret 值对 AI 自动脱敏
- **AI 能力**保留顶级：运行时开关（对话中高频切换）+ 自定义工具注册，非纯配置
- 设置页支持 `?tab=` 深链；旧路由 /models、/env-vars 永久 redirect 兼容
- **无订阅系统**：个人自部署、BYO-Key，设置中心不含「订阅」Tab

已删除旧路由：`/agents`（智能体）、`/tasks`（任务中心）——概念合并入「自动任务」和「环境控制台」。

## 6. 业务流程闭环（2026-09-03 补全）

| 流程 | 状态 | 关键交互 |
|------|------|---------|
| 文件 → 知识库 → 对话 → 沉淀 | ✅ 已闭环 | 回答带引用来源卡片；「保存到知识库」写入对话产出分组；能力状态条实时联动 |
| 数据源 → 查询 → 结果去向 | ✅ 已闭环 | 结果栏「导出 CSV」（真实下载）+「保存为自动任务」 |
| 环境异常 → 诊断 → 处置 | ✅ 已闭环 | AI 诊断「创建修复任务」直达自动任务页 |
| 自动任务 → 执行 → 结果 → 通知 | ✅ 已闭环 | 新建任务弹窗；执行历史 Tab（含失败重试）；任务动作推送系统通知（未读角标） |
| 未索引文件 → 索引 | ✅ 已闭环 | 文件表「加入知识库」虚线按钮 → 索引徽章 + 通知 |
| 全局搜索 | ✅ 真实搜索 | Cmd+K 跨文件/知识库/数据源/服务/任务分组检索，回车跳转 |
