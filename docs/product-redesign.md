# 产品重定位设计 · 个人文件管理 + 开发者工作台

> 状态：已实施 · 范围：全站页面/数据/文档统一重命名 · 日期：2026-09-03

## 1. 定位变更

| 维度 | 旧定位 | 新定位 |
|------|--------|--------|
| 产品名 | AI 个人文件工作台 | Nora 个人工作台 |
| 目标用户 | 模糊的「商业用户」 | 个人用户 + 开发者 |
| 核心价值 | AI 员工的办公室 | 用自然语言管文件、查数据库、控制环境 |

## 2. 页面架构

```
/               概览（数据源/环境/知识库状态面板）
/files          文件管理（AI 索引徽章）
/chat           AI 对话
/knowledge      知识库 RAG（5 Tab：文档库/检索测试/索引状态/数据图谱/清洗规则）
/skills         AI 能力（原「技能中心」，定义 AI 能做什么）
/data-sources   数据源（连接列表 + Schema 浏览 + 查询控制台）
/environments   环境控制台（服务卡片 + 日志流 + AI 诊断）
/automations    自动任务（触发条件 → 执行动作）
/settings       设置
```

已删除旧路由：`/agents`（智能体）、`/tasks`（任务中心）——概念合并入「自动任务」和「环境控制台」。

## 3. 术语统一

| 旧术语 | 新术语 | 理由 |
|--------|--------|------|
| 智能体 | —（已移除） | AI 员工人设与新产品无关 |
| 技能中心 | AI 能力 | 定义 AI 的权限边界 |
| 任务中心 | 自动任务 | 触发→动作模型 |
| 产品助理/数据分析师（文件标签） | 已索引（知识库徽章） | 文件的 AI 属性是索引状态 |
| 企业数据源（Salesforce/Jira） | 本地/测试数据库 + Redis | 开发者场景 |

## 4. 数据层

| 文件 | 内容 |
|------|------|
| `mockData.ts` | 个人文件（含 indexed 标志）+ AI 能力 |
| `devData.ts` | 数据库连接、表结构、查询历史、服务、日志、自动任务 |
| `knowledgeData.ts` | RAG 文档、索引统计、清洗规则、检索结果、数据图谱 |
